# embankment_co2e
Repository holding the code to calculate the embodied carbon in a reinforced soil embankment, and a streamlit application

Can be accessed at the following:
https://embankment-co2e.streamlit.app/

If you see an image like this, just click the _Yes, get this app back up!_ button.

<img src="https://docs.streamlit.io/images/streamlit-community-cloud/app-state-zzzz.png" alt="Sleep image" height="200">

The platform which the app is on just closes it down to save resources if no-one has accessed it in a while. More info [here](https://docs.streamlit.io/deploy/streamlit-community-cloud/manage-your-app#app-hibernation)

## Notes
* The image file is manually converted from the PDF in the folder, and then included in the app.
